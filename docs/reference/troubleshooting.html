Troubleshooting

Undo Winhance changes, fix the problems Winhance tells you about, find the log files and report a bug.

Undo changes

Pick the option that matches how far back you want to go.

Put back the settings you had before Winhance

On its first launch, Winhance saves a backup config with the value every setting had at that moment. It lives in %LOCALAPPDATA%\Winhance\Backup as UserBackup_<date>.winhance.

  1. Open the import window

    Go to Settings > Backup & Restore and click Import.

  2. Choose the backup

    Choose Import backup config.

  3. Review and apply

    Click Continue. Winhance opens the backup in Config Review. Check the changes, then click Apply Config. If you ticked Skip review and apply immediately, it applies straight away.

Reset to Windows defaults

To set one page back to how Windows ships, open it and choose Quick Actions > Reset to Windows Defaults. To reset everything at once, click Import under Backup & Restore and choose Restore Windows defaults.

Roll back with System Restore

If you created a restore point when Winhance offered one, or later from Settings > System Restore Point, Windows can roll the whole system back to it. Search the Start menu for Create a restore point, click System Restore, and pick the point named Winhance Restore Point with the date you made it.

Removed apps and leftover scripts

When you remove some Windows apps, Winhance can save a removal script and a scheduled task that removes them again if Windows puts them back. To stop that, for example because you want an app back:

  1. Open the help

    Go to Software & Apps, open the Windows Apps tab and click Help.

  2. Delete the script

    Under Winhance Status, click an active entry to delete its script and scheduled task.

Then reinstall the app from the same tab, if it can be reinstalled. Each app card shows whether it can. To see the scripts themselves, choose More > Winhance Scripts.

A setting says "Not recognized", "Wrong format" or "Couldn't read"

  • Not recognized: the current value doesn't match any option Winhance knows. You can leave it as it is, or pick one of the listed options.
  • Wrong format: the value is stored in the wrong format, so Winhance can't read its state. Pick an option and Winhance repairs the format at the same time.
  • Couldn't read: Winhance couldn't read the setting at all. The reason is in the log file.

A change doesn't show up

Some taskbar and File Explorer settings only take effect after Explorer restarts. When Winhance shows Some changes need Explorer restarted to take effect., click Restart Explorer. Other settings need Windows to restart. After you apply a config, Winhance recommends a restart.

An app won't install

  • Windows Updates Disabled: Microsoft Store apps can't finish installing while Windows Update is turned off. Winhance offers to set the update policy to Paused for a long time and try again.
  • Package not found in WinGet: this is usually a regional restriction on a Windows app. Winhance offers to download the package directly from Microsoft's servers instead.
  • Network error: installs from WinGet need an internet connection. Check it and try again.
  • winget was terminated: Winhance stops WinGet if it stops responding or runs past its time limit. Try the install again. If it keeps happening, report it with your log file.

"Running as a different user"

This bar appears when you started Winhance by typing another account's administrator password, for example on a standard account. It's for your information only. Winhance still applies settings to the account that is signed in.

An old config file won't import

Winhance shows Unsupported Configuration Version for config files from versions before the current format. Set your choices again in Winhance and save a new file. Files in the current format keep working in later versions.

WIMUtil problems

  • Not enough space: Winhance shows how much space extracting or building the ISO needs, how much the drive has, and how much more to free. Free up space or pick another drive.
  • Invalid directory: pick a folder that holds the extracted contents of a Windows ISO.
  • File larger than 4 GB on USB: FAT32 can't hold files over 4 GB, and Winhance can only split sources\install.wim. Convert an ESD image to WIM in the earlier step, or remove the large file from the working folder.

The WIMUtil guide walks through each step.

Windows Setup installs the wrong edition

Many PCs carry a product key in their firmware, and Setup can use it to choose the edition by itself. In Builder mode with Autounattend selected, set Windows edition to the edition you want, or to Use my own product key. The edition must be on the installation media.

Log files and change history

FileWhereOpen it from
App log, one per sessionC:\ProgramData\Winhance\Logs\Winhance_Log_<date>_<time>.logMore > Winhance Logs
Startup log, rewritten on each launchC:\ProgramData\Winhance\Logs\WinhanceStartupLog.txtMore > Winhance Logs
Change historyC:\ProgramData\Winhance\ChangeHistory.txtMore > Change History

The change history lists every setting change, app install and app removal Winhance made, newest at the bottom. If Winhance closes before its window appears, the startup log shows how far it got.

Report a bug

Click the bug icon in the title bar, or choose More > Report a Bug. Both open Winhance's GitHub Issues. Choose Report a bug or an issue and fill in:

  • your Winhance version (the first line of the More menu),
  • your Windows version, edition and architecture,
  • the steps that cause the problem, and what you expected to happen,
  • your latest log file from C:\ProgramData\Winhance\Logs.

Search the open and closed issues first, and check that the problem still happens in the latest release.
