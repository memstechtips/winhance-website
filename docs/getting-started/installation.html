Installation

Install Winhance with the installer, as a portable copy, or with one PowerShell command, and keep it up to date.

Every method uses the same file, Winhance.Installer.exe, from the latest GitHub release. The installer asks whether you want a regular installation or a portable one.

System requirements

  • Windows 10 or Windows 11.
  • A 64-bit (x64) PC. The installer also runs on Windows 11 on Arm, where Windows runs Winhance through x64 emulation. There is no 32-bit version.
  • Administrator rights. Winhance always starts elevated, so Windows shows a User Account Control prompt each time you open it.

You don't need to install .NET or any other runtime first. Winhance ships with everything it needs. An internet connection is needed to download Winhance, to check for updates, and to install apps from the Software & Apps page.

Install with the installer

  1. Download the installer

    Download Winhance.Installer.exe from the latest release, or use the download button on the Winhance home page.

  2. Choose the installation type

    Run the file and accept the license. Under Installation type, choose Perform a regular installation or Perform a portable installation. For a regular installation you can also pick Create a shortcut on the Desktop and Create a shortcut in the Start menu.

  3. Pick a folder

    By default, a regular installation goes to C:\Program Files\Winhance and a portable one to a Winhance folder on your desktop. You can change the folder before you continue.

  4. Finish and launch

    When setup finishes, leave the launch box ticked to open Winhance, then accept the User Account Control prompt.

Regular or portable?

RegularPortable
Default folderC:\Program Files\WinhanceDesktop\Winhance
ShortcutsDesktop and Start menu, if you tick themNone
UninstallerYes, in Windows Settings under installed appsNo, delete the folder

Both run the same app with the same features. You can move a portable folder anywhere, including to a USB drive. Either way, Winhance keeps its logs, scripts and change history in C:\ProgramData\Winhance, and the backup config it makes on first launch in %LOCALAPPDATA%\Winhance\Backup. Uninstalling, or deleting a portable folder, leaves those in place.

Install with PowerShell

This one command downloads the installer and runs it for you, without the setup wizard.

  1. Open PowerShell as administrator

    Right-click the Start button and choose Terminal (Admin) or Windows PowerShell (Admin).

  2. Run the command

    irm "https://get.winhance.net" | iex

  3. Pick normal or portable

    Type 1 for Normal Installation or 2 for Portable, then press Enter.

What the script does next:

  • It downloads the latest Winhance.Installer.exe from GitHub to C:\ProgramData\Winhance\Unattend\WinhanceInstaller.exe.
  • Normal installs Winhance silently to C:\Program Files\Winhance with Desktop and Start menu shortcuts, then opens it.
  • Portable puts Winhance in a Winhance folder on your desktop, then opens it. You can move that folder anywhere.

The downloaded installer stays in C:\ProgramData\Winhance\Unattend. You can delete it once Winhance is running. See Command line for the installer switches the script uses.

Updates

Each time Winhance starts, it checks GitHub for a newer release. If there is one, an Update Available bar shows your version and the latest one. If there isn't, Winhance says nothing.

  1. Download the update

    Click Install Now on the bar. To check yourself, open More at the bottom of the sidebar and choose Check for Updates.

  2. Relaunch

    When the download finishes, click Relaunch. Winhance closes, the installer updates it in the same folder, and Winhance opens again.

A portable copy stays portable and a regular installation stays regular, so the update never moves your copy somewhere else. To see which version you have, open More: the version is the first line of the menu.

Uninstall

For a regular installation, uninstall Winhance from installed apps in Windows Settings. For a portable copy, close Winhance and delete its folder.

Uninstalling doesn't undo changes Winhance made to Windows. Undo those first if you want them gone, as described in Troubleshooting.
