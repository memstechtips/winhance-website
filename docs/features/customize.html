Customizations

The Customize page: theme, taskbar, Start menu, File Explorer, and time, region and language, every setting with what it changes in Windows.

Customize changes how Windows looks and behaves: the theme and desktop background, the taskbar, the Start menu, File Explorer, and time, region and language. Each setting shows which option Windows uses by default and which one Winhance recommends. In Normal mode, a change applies to this PC as soon as you make it.

Windows Theme Light or dark mode for Windows and apps, transparency effects and the desktop background. 11 settings Taskbar Taskbar alignment, the search box, Task View, widgets and the other taskbar buttons, and how the taskbar behaves. 29 settings Start Menu The Start menu layout and what it recommends and shows. 13 settings Explorer File Explorer, the desktop, the right-click menu, This PC folders, the navigation pane and file associations. 76 settings Time & Region Time zone, region, display language, keyboard layout, and the date, time, number and currency formats. 12 settings

Looking for animations, shadows and the other visual effects? They are on the Gaming & Performance page, under Visual Effects.
