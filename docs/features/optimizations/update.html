Windows Update

When Windows Update installs updates, whether it includes drivers, and how updates are delivered.

Flip any switch in the window above to see what Winhance would write to Windows.

How Windows Update installs updates, when it restarts, what it downloads and over which connections, and whether it brings driver updates.

Keep security updates on

Pausing or turning off updates leaves the PC without security fixes. Security Updates Only (Recommended) keeps security updates coming and defers feature updates by a year.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.

Driver Co-Installers

Allows hardware vendors to install companion software alongside device drivers. Disabling this prevents bloatware like Razer Synapse, printer utilities, and other vendor software from being automatically installed when you plug in devices. Your hardware will still work normally with standard drivers.
