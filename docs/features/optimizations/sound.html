Sound Optimizations

The startup sound and what Windows does to other audio while you are on a call.

Flip any switch in the window above to see what Winhance would write to Windows.

The startup sound, what Windows does to other audio during calls, voice activation for apps, and the sounds accessibility shortcuts make.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.

System Sounds

The startup sound, how much Windows lowers other audio during calls and while Narrator speaks, voice activation for apps, and accessibility sounds.
