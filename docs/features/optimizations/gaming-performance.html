Gaming & Performance

Processor and graphics scheduling, network tweaks, Xbox and Game Bar, background services and tasks, and visual effects.

Flip any switch in the window above to see what Winhance would write to Windows.

Settings that cut background work and latency so games and heavy apps get more of the PC: processor and GPU priority, network tweaks, Windows services and scheduled tasks, and visual effects.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.

General

Game Mode, mouse acceleration, menu and hover delays, the startup delay for apps, background app permissions, Storage Sense, search scope and System Protection.
