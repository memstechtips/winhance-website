Privacy & Security

Telemetry, ads and suggestions, lock screen, app permissions, the Windows AI features, and security settings like User Account Control and automatic BitLocker encryption.

Flip any switch in the window above to see what Winhance would write to Windows.

What Windows collects and shares, the ads and suggestions it shows, which apps can use your camera, microphone and location, its AI features, and core security options such as User Account Control.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.
