Time, Region and Language

Time zone, region, display language, keyboard layout, and the date, time, number and currency formats.

Flip any switch in the window above to see what Winhance would write to Windows.

The time zone, regional format, home location, display language and keyboard layout, plus the formats Windows uses for dates, numbers and currency, all on one page.

Most dropdowns here are filled by Windows itself, so their lists differ from one PC to another. Their tables name the values Winhance writes rather than every choice.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.

Time

The time zone this PC keeps its clock in. The change takes effect as soon as you apply it.
