Windows Theme

Light or dark mode for Windows and apps, transparency effects and the desktop background.

Flip any switch in the window above to see what Winhance would write to Windows.

Light or dark mode, transparency, and the desktop background.

Technical Details

Each setting below lists exactly what Winhance reads and writes: registry values, scheduled tasks, power settings and scripts, with the recommended value and the Windows default marked. It is the same table the app shows when you turn on Technical Details in the View menu.

Theme mode

Light or dark for Windows and apps. Choose your mode sets both at once; the two toggles below it set apps, such as Settings and File Explorer, and the Windows shell, such as the taskbar and Start menu, separately.

Background

The desktop background: a picture, a solid color, a slideshow or Windows spotlight, and how a picture fits the screen. For a picture you can pick one of Windows' own, keep the one this PC has, choose one Windows showed recently, or browse for your own. Windows' own pictures and their file paths are listed below.

Desktop background

A picture, a solid color or a slideshow, and how it fits the screen. Choose one of Windows' own pictures, keep this PC's, or browse for your own.

PreferenceAdded in v26.09.10
theme-wallpaper
When set to Windows spotlight

Winhance can detect Windows Spotlight but cannot turn it on: Windows offers it only in its own Settings and gives apps no supported way to select it. That is a Windows limitation, not a Winhance one. Choosing another background here is one-way - to return to Spotlight, use Windows Settings > Personalization > Background. Spotlight also leaves Windows' own list while Content Delivery or Subscribed Content are off on the Privacy page. A saved config records Spotlight but cannot restore it either.

PowerShell ScriptsWinhance runs this script when you apply the matching option.
On Apply
$album = '{{value}}'
                $slideshowKey = Get-ItemProperty -Path 'HKCU:\Control Panel\Personalization\Desktop Slideshow' -ErrorAction SilentlyContinue
                $desktopKey = Get-ItemProperty -Path 'HKCU:\Control Panel\Desktop' -ErrorAction SilentlyContinue
                $interval = if ($slideshowKey.Interval) { [int]$slideshowKey.Interval } else { 1800000 }
                $shuffle = $slideshowKey.Shuffle -eq 1
                Add-WinhanceDesktopType
                $position = [Winhance.Desktop.DesktopBackground]::Position("$($desktopKey.WallpaperStyle)", "$($desktopKey.TileWallpaper)")
                try {
                    [Winhance.Desktop.DesktopBackground]::Slideshow($album, $position, $interval, $shuffle)
                    Write-Log "Desktop background set: slideshow of $album" "SUCCESS"
                } catch {
                    Write-Log "Desktop background slideshow failed: $($_.Exception.Message)" "ERROR"
                    # One picture rather than none: the album's first, or the Windows picture matching the theme this file
                    # just applied, so a failure here cannot leave a light desktop under a dark shell.
                    $first = Get-ChildItem -LiteralPath $album -File -ErrorAction SilentlyContinue | Sort-Object Name | Select-Object -First 1
                    if ($first) {
                        $path = $first.FullName
                    } else {
                        $personalize = Get-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize' -ErrorAction SilentlyContinue
                        if ($personalize.SystemUsesLightTheme -eq 0) { $path = 'C:\Windows\Web\Wallpaper\Windows\img19.jpg' }
                        else { $path = 'C:\Windows\Web\Wallpaper\Windows\img0.jpg' }
                    }
                    try {
                        [Winhance.Desktop.DesktopBackground]::Picture($path, $position)
                        Write-Log "Desktop background set to $path instead" "SUCCESS"
                    } catch {
                        Set-RegistryValue -Path 'HKCU:\Control Panel\Desktop' -Name 'WallPaper' -Type 'String' -Value $path -Description 'The desktop background picture'
                        Set-RegistryValue -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Wallpapers' -Name 'BackgroundType' -Type 'DWord' -Value 0 -Description 'The desktop background picture'
                        Write-Log "Desktop background recorded as $path; it shows at the next sign-in" "WARNING"
                    }
                }
