Configuration files

Save your Winhance settings and app choices to a .winhance file, then import it on this PC or another one, with a review step before anything changes.

A config is a .winhance file. It holds the value of every Winhance setting plus the apps you checked under Software & Apps. Use one to set up a second PC the same way, to keep your choices safe before you reinstall Windows, or to share a setup with someone else.

What a config contains

SectionWhat it holds
WindowsAppsThe Windows apps, capabilities and optional features you checked.
ExternalAppsThe External Software apps you checked, with their WinGet IDs.
OptimizeOne entry per Optimize page (Privacy & Security, Power, Gaming & Performance, Update, Notifications, Sound) with the value of each setting.
CustomizeThe same for the Customize pages: Windows Theme, Taskbar, Start Menu, Explorer, and Time, region and language.
AutounattendAnswer-file choices from the Unattend page, when the file has any.

A saved config also records the name of the PC it came from, so you can tell files from different machines apart. A file made in Builder mode for one Windows release records that release too.

Save a config

There are two ways to save one.

  • From this PC as it is now. Open Settings, find Backup & Restore and click Export. The file gets the current value of every setting on this PC, plus whichever apps you have checked on the Software & Apps page. Check the apps you want in the file before you export.
  • From choices you make without applying them. Switch the Winhance Mode selector in the title bar to Builder, pick Config on the Builder bar, set things the way you want, then click Save Config. Nothing changes on this PC. See Builder mode for the starting points and the target Windows picker.

If no Windows apps are checked, Winhance asks before saving, because the imported file would then check no apps.

Import a config

  1. Open the import window

    Click Import under Settings > Backup & Restore, or switch the Winhance Mode selector to Config Review. Both open the Import Config window.

  2. Pick a source

    Choose one of the four options:

    • Import my own config: a .winhance file from your computer.
    • Import recommended config: the config that ships with Winhance (see below).
    • Import backup config: the backup Winhance made the first time it ran on this PC.
    • Restore Windows defaults: the values a clean install of Windows uses. Winhance loads the Windows 11 25H2 defaults on Windows 11 and the Windows 10 22H2 defaults on Windows 10.

  3. Review it, or apply it straight away

    Leave Skip review and apply immediately unticked and click Continue to open the config in Config Review mode. Tick it to apply the config without reviewing, using the options in the next section.

Skip review and apply immediately

Ticking the box turns on these options:

  • Windows Apps: Install, Uninstall (the default) or Select Only. Select Only checks the apps on the Software & Apps page and leaves the removal to you.
  • External Apps: Install (the default), Uninstall or Select Only.
  • Clean Taskbar and Clean Start Menu: ticked by default. Each one runs only if the config itself has it selected.

Click Continue. Winhance shows a progress overlay while it works, then tells you when the configuration is applied. Some settings only take effect after a restart, so restart when it finishes.

Config Review mode

Config Review compares the config with this PC and shows you every change before anything is applied. It is a review screen, not an editor, and the normal app actions are turned off while you are in it.

  • Every setting stays on screen. A setting the config would change shows its current value and the config's value, with Apply and Don't apply buttons.
  • To see only the settings that would change, open the View menu and turn on Show Only Changes.
  • On the Software & Apps page, tick the apps you want and choose Install or Uninstall. Leave none ticked to skip apps.
  • The bar at the top counts your progress, for example "12 of 40 reviewed (9 will be applied)". Settings in the file that this PC does not have are set aside, and the bar says how many.
  • Apply Config becomes available once you have decided on every change. Cancel leaves review mode without changing anything.

The backup config

The first time Winhance runs, it saves the current value of every setting and the list of installed Windows apps to %LOCALAPPDATA%\Winhance\Backup, as UserBackup_date_time.winhance. Import it with Import backup config to put the settings Winhance manages back the way they were. If the folder holds more than one backup, Winhance asks which one to use.

Make a restore point too

The backup config only covers settings Winhance knows about. A System Restore point covers the rest. You can create one from the Settings page.

The recommended config

Import recommended config loads the config that ships inside Winhance. It covers every Optimize and Customize page, checks most of the built-in Windows apps for removal, and checks these External Software apps for installation:

Brave, ONLYOFFICE Desktop Editors, SumatraPDF, OBS Studio, MPC-BE, Greenshot, FastStone, Nilesoft Shell, StartAllBack, Steam, 7-Zip, File Converter, UniGetUI and Notepad++.

Import it with review on the first time, so you can see what it would change and skip anything you want to keep.

File format

A .winhance file is indented JSON. You can open it in any text editor. A short file looks like this:

{
  "Version": "2.0",
  "CreatedAt": "2026-10-01T09:30:00Z",
  "ComputerName": "DESKTOP-01",
  "WindowsApps": {
    "IsIncluded": true,
    "Items": []
  },
  "ExternalApps": {
    "IsIncluded": true,
    "Items": [
      {
        "Id": "external-app-brave",
        "Name": "Brave",
        "IsSelected": true,
        "InputType": 0,
        "WinGetPackageId": "Brave.Brave"
      }
    ]
  },
  "Customize": {
    "IsIncluded": true,
    "Features": {
      "WindowsTheme": {
        "IsIncluded": true,
        "Items": [
          {
            "Id": "theme-mode-windows",
            "Name": "Choose your mode",
            "InputType": 1,
            "SelectedIndex": 1
          }
        ]
      }
    }
  },
  "Optimize": {
    "IsIncluded": true,
    "Features": {
      "Privacy": {
        "IsIncluded": true,
        "Items": [
          {
            "Id": "privacy-diagnostics",
            "Name": "Send Diagnostic Data",
            "IsSelected": false,
            "InputType": 0
          }
        ]
      }
    }
  }
}

Each setting is stored by its Id. A toggle stores IsSelected, a dropdown stores SelectedIndex, and other controls store their own value fields. A real export lists every setting, not just one per page.

Only version 2.0 files load

Winhance refuses a file whose Version is not 2.0. If an old config is refused, set Winhance up the way you want and export a new one.
