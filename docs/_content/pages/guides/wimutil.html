WIMUtil

Build your own Windows installation media from a Windows ISO: add an answer file and drivers, then save a new ISO or write it straight to a USB drive.

WIMUtil (Windows Installation Media Utility) is the WIMUtil page in the left navigation. Use it when you want to install Windows with your settings already baked in, or reinstall Windows on a PC and have its drivers ready from the first boot. It works in four steps. Step 1 has to finish first; steps 2 to 4 unlock after it, and steps 2 and 3 are optional.

WIMUtil is not available while you are in Config Review mode.

  1. Select Windows ISO

    You need a Windows 10 or Windows 11 ISO. If you don't have one, the Windows 10 and Windows 11 buttons next to Download Windows ISO open Microsoft's download pages.

    • Click Select ISO and choose the ISO file.
    • Under Select working directory, keep the default folder (%TEMP%\WinhanceWIM) or click Select Folder to pick a drive with more space. Winhance creates a WinhanceWIM folder inside the one you pick. The ISO's contents are copied here, and everything you add in the next steps goes here too.
    • Click Start Extraction. If the drive is too small, Winhance tells you how much more space it needs.

    Already extracted an ISO before? Tick I have extracted ISO contents already, then click Select Folder and choose that folder. Winhance checks it has the sources and boot folders and skips the extraction.

    Convert the image format (optional)

    After extraction, WIMUtil reads the Windows image on the media and offers to convert it. install.wim is larger; install.esd is more compressed, so the finished media is smaller. The card shows the current size and an estimate after conversion. Most people can skip this. The one time you need it is writing an ESD image larger than 4 GB to a USB drive (see step 4).

    If the folder has both install.wim and install.esd, Winhance asks you to delete one with Delete WIM or Delete ESD before you continue.

  2. Add XML File

    An answer file (autounattend.xml) lets Windows Setup install without stopping to ask questions, and carries your settings onto the new PC. Pick one of three options. Whichever you choose, the file goes in the root of the media, where Setup looks for it.

    • Generate and add Winhance XML: click Set up the answer file. Winhance enters Builder mode with the Autounattend target, and the answer-file settings open inside this card. If the media carries a single Setup language, Winhance picks it for you, and it sets the target Windows to the build on your media. Go through the settings and the other pages you want to include, then click Generate and add XML to media at the end. See the answer file guide for what goes into the file.
    • Download & add UnattendedWinstall XML: click Download to fetch the latest ready-made file from the UnattendedWinstall project. Needs an internet connection.
    • Select XML File: click Select XML to use an autounattend.xml you already have, from Winhance or another generator. The Schneegans XML button below the options opens one such generator in your browser.

    When you generate from Winhance, a confirmation window lists what is about to happen first: where the file is written, which installers are downloaded onto the media, and which of your own installers are copied. When it finishes, a summary shows which apps made it onto the media. An app that could not be put on the media downloads after setup instead.

    After any of the three options, Winhance checks the answer file for problems Windows Setup would trip over and shows the result. The check never blocks you: if it finds something, you can read each finding and click Continue anyway.

  3. Extract and Add Drivers

    Adding drivers means your network, graphics and other hardware work from the first boot.

    • Extract and add drivers from current OS (Recommended): click Extract & Add to copy every third-party driver installed on this PC onto the media. Use this when you are reinstalling Windows on the same PC.
    • Add other drivers: click Select & Add and pick a folder that contains driver .inf files. These are added alongside any drivers already on the media.

    Winhance sorts the drivers as it copies them. Storage controller drivers go in the $WinpeDriver$ folder at the root of the media, so Setup can see your disks. Everything else goes in sources\$OEM$\$$\Drivers, which Setup copies to C:\Windows\Drivers. The answer file then installs those drivers while Windows sets itself up, before the first setup screens appear, and deletes each driver folder once its driver is in.

    The answer file needs one extra command for this. Winhance adds it to whichever answer file you chose in step 2. If you added drivers but no answer file, Winhance writes a small autounattend.xml that only installs the drivers.

  4. Create New ISO

    Under Output destination, choose ISO file or USB drive.

    ISO file

    • Click Select Location and choose where to save the ISO.
    • Click Create ISO.

    The ISO boots on both UEFI and older BIOS PCs. Winhance builds it with Windows' own disc-image tools, so there is nothing extra to download. When it is done, you can open the folder that holds it.

    USB drive

    • Plug in a USB drive and pick it from the Select USB drive list. Click Refresh list if it is not there. Only USB drives are listed, never the disk Windows runs from.
    • Click Write to USB, then confirm with Erase and write.

    Writing erases the USB drive

    The drive is formatted first, so everything saved on it is deleted.

    The drive is formatted as FAT32 so every PC can boot it. FAT32 cannot hold a file over 4 GB, so Winhance splits a large install.wim into smaller pieces that Setup reads as one. It cannot split install.esd: if yours is over 4 GB, convert it to WIM in step 1 first. A FAT32 drive is limited to about 32 GB, so media larger than that cannot be written to one drive. Keep the working directory on a different drive from the USB you are writing to.

After you install

Boot the PC from the ISO or USB drive and install Windows as usual. What happens next depends on the answer file. With a Winhance answer file, see what happens during installation.

Drivers that failed to install stay in C:\Windows\Drivers, and the install log is at C:\ProgramData\Winhance\Unattend\Logs\Winhance-DriverInstall.log. To install one by hand, open Device Manager, right-click the device, choose Update driver > Browse my computer for drivers and point it at that folder.
