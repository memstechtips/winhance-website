WIMUtil

Build your own Windows installation media from a Windows ISO. Choose what to build into the Windows image and what to run during Setup, then save a new ISO or write it straight to a USB drive.

WIMUtil (Windows Installation Media Utility) is the WIMUtil page in the left navigation. It has four steps. Extract or select the media first, then decide how Windows is built, which changes to include and where to save the result. You can leave the optional changes blank to create media without an answer file, drivers or updates.

WIMUtil is not available while you are in Config Review mode.

  1. Your ISO

    You need a Windows 10 or Windows 11 ISO. The Windows 10 and Windows 11 buttons next to Download Windows ISO open Microsoft's download pages.

    • Click Select ISO and choose the ISO file.
    • Under Select working directory, keep the default folder (%TEMP%\WinhanceWIM) or click Select Directory to pick a drive with more space. Winhance creates a WinhanceWIM folder inside the one you pick. Choose a local NTFS drive if you want to build changes into the image.
    • Click Start Extraction. If the drive is too small, Winhance tells you how much more space it needs.

    Already extracted an ISO before? Tick I have extracted ISO contents already, then click Select Folder and choose a writable folder containing the extracted media, including the sources and boot folders.

  2. How it's built

    Under How should your changes reach Windows?, choose one of two methods:

    • During setup (Autounattend only) leaves the Windows image unchanged. Your changes apply while Windows Setup runs.
    • Built into the image (DISM + Autounattend) uses Windows offline servicing to build supported app removals, settings, drivers and updates into the image when you create the media. Choices that need Windows Setup still use an answer file.

    For the second method, choose an edition under Edition to keep if the image contains more than one. Winhance keeps that edition and removes the others during creation. If the working folder is not on a local NTFS drive, drivers and the update install during Setup instead. If both install.wim and install.esd exist, delete one using Delete WIM or Delete ESD.

    Under Answer file, pick Winhance XML to build an answer file from your choices, or Your own XML to use a file you already have. The latter can be an UnattendedWinstall file or one you made with another tool. The Schneegans XML button opens an answer file generator. An answer file already on the media is flagged, with an option to delete it. Winhance can also reopen choices from an answer file it generated in a version that stores those choices.

    Winhance checks answer files for problems. A malformed XML file cannot be added. The detailed check reports errors and warnings, and you can choose to continue despite its findings. A clean result is not a guarantee that every script or Windows Setup action will succeed.

  3. What changes

    If you chose Winhance XML, use Builder mode to select the Windows apps to remove, external apps to install, and the Optimize and Customize settings to apply. The In the image and During setup tags show how the changes reach Windows. Open the Unattend page for Setup-specific choices, such as accounts and setup screens. See the answer file guide.

    Under Drivers and updates, select what to include:

    • Add this PC's drivers copies third-party drivers from the current PC. Use this when reinstalling Windows on the same PC.
    • Add drivers from a folder adds drivers from a folder containing .inf files.
    • Add the latest Windows update adds the cumulative update Winhance finds for the media's Windows build. The card shows its KB number, release date and download size. Winhance checks the Microsoft download against Microsoft's published hash and signature. If the media is already up to date or no update is available, the option stays off.

    With the During setup method, Windows Setup installs the drivers before the first startup screens and installs the staged update at first sign-in, then restarts. With the Built into the image method, Winhance tries to install them into the image first. If that fails, a message tells you which changes fall back to Setup. Storage drivers are available on the media for Setup to find your disks.

    With the Built into the image method, Clean up the image also offers options to remove old component versions, downloaded update files, archived servicing logs, temporary files and crash reports. Removing old component versions means you cannot uninstall updates built into the image afterwards.

  4. Create

    Under Image format, choose WIM for quicker creation or ESD for smaller media. Winhance converts the image when needed during creation. Unlike a FAT32-only USB drive, the USB layout Winhance creates can hold large WIM and ESD files without splitting them.

    Under Output destination, choose ISO file or USB drive. If the media offers both Secure Boot certificates, Secure Boot compatibility lets you choose the 2011 certificate accepted by most PCs or the 2023 certificate for updated PCs.

    ISO file

    • Click Select Location and choose where to save the ISO.
    • Click Create ISO.

    The ISO boots on both UEFI and older BIOS PCs. When it is done, you can open the folder that holds it.

    USB drive

    • Plug in a USB drive and choose it under Select USB drive. Use Refresh list if needed. USB hard drives and SSDs only appear if you tick Show USB hard drives.
    • Click Write to USB and confirm with Erase and write.

    Writing erases the USB drive

    Everything on the selected drive is deleted. Keep the working directory on a different drive from the USB you are writing to.

    Winhance creates a small FAT32 boot partition and an NTFS installation partition. The FAT32 partition holds the files needed to start Windows Setup; the NTFS partition holds the installation files, including large Windows images. This layout boots on UEFI and legacy BIOS without requiring image splitting.

    When you build with Winhance XML, review the creation plan before confirming. Winhance prepares the answer file and any chosen offline installers, builds the media, and shows the results. External apps that could not be staged download after Setup instead. Delete the working folder after a successful build is available only for the folder Winhance extracted the ISO into, and only if the output ISO is not inside it.

After you install

Boot the PC from the ISO or USB drive and install Windows. What happens next depends on your choices. With a Winhance answer file, see what happens during installation.

If drivers were staged for Setup, drivers that failed to install stay in C:\Windows\Drivers, and the install log is at C:\ProgramData\Winhance\Unattend\Logs\Winhance-DriverInstall.log. To install one by hand, open Device Manager, right-click the device, choose Update driver > Browse my computer for drivers and point it at that folder.
