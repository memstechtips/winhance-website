Winhance documentation

How to install Winhance, find your way around the app, and use each of its pages to clean up and set up Windows.

Winhance is a free Windows 10 and 11 app that removes the apps you don't want, installs the ones you do, and changes Windows settings for privacy, performance and looks. It can also save your choices to a file and build an answer file that applies them while Windows installs on a new PC.
