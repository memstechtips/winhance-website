Releases

Where to find what changed in each Winhance release, and how to read a Winhance version number.

Release notes

Every release, with its notes and its download, is on GitHub Releases. That page is the changelog. This site doesn't keep a separate copy.

Each release carries Winhance.Installer.exe, the one file that installs both the regular and the portable version. To follow new releases, click Watch on the Winhance repository and choose to be notified about releases.

Version numbers

A Winhance version is the release date, written as vYY.MM.DD.

VersionMeaning
v26.06.12The release of 12 June 2026.
v26.05.27-betaA beta build from 27 May 2026. Beta builds show Release-Preview: Version is for Testing Only in the title bar.

A later date always means a newer version, and that is how the updater decides whether yours is out of date. To see your version, open More in the sidebar. The first line of the menu reads Winhance followed by the version.

Updating

Winhance checks for a new release each time it starts, and you can check any time from More > Check for Updates. Installation explains how the update installs.
