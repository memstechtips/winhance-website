Command line

The PowerShell install command, the installer's silent-install switches, and the two app-install flags Winhance accepts at startup.

Winhance is a windowed app. It has no command-line mode for applying settings or configs. Use the app's Config Review or Builder modes for that. What you can script is installing Winhance, and telling it which apps to install when it opens.

Install command

irm "https://get.winhance.net" | iex

irm (Invoke-RestMethod) downloads the Winhance install script and iex (Invoke-Expression) runs it. The script asks for a normal or portable installation, downloads the latest Winhance.Installer.exe from GitHub, installs Winhance with the switches below, and opens it. Installation walks through it step by step.

Installer switches

Winhance.Installer.exe is an Inno Setup installer. Winhance's install script and in-app updater run it silently with /SILENT /SUPPRESSMSGBOXES, pick the installation type with /TASKS or /MERGETASKS, and the updater adds /DIR="<folder>" so the update lands in the same folder.

The tasks are:

TaskMeaning
regularinstallRegular installation with an uninstaller. Picked by default.
regularinstall\desktopiconDesktop shortcut (regular installation only).
regularinstall\startmenuiconStart menu shortcut (regular installation only).
portableinstallPortable copy, with no uninstaller or shortcuts.

These are the two commands the install script uses. Regular installation with both shortcuts:

Start-Process .\Winhance.Installer.exe -ArgumentList '/SILENT /SUPPRESSMSGBOXES /MERGETASKS="regularinstall\desktopicon,regularinstall\startmenuicon"' -Wait

Portable copy, which lands in a Winhance folder on the desktop:

Start-Process .\Winhance.Installer.exe -ArgumentList '/SILENT /SUPPRESSMSGBOXES /TASKS="portableinstall"' -Wait

Winhance.exe flags

Winhance accepts two flags. Answer files made by Winhance use them to install your chosen apps on a new PC after Windows Setup. You can use them yourself too.

FlagWhat it does
--install-apps <ids>Installs these External Apps once Winhance has loaded. Separate the IDs with commas.
--install-folder <folder>Also runs the installers staged in this folder. Winhance's answer files point it at C:\ProgramData\Winhance\Unattend\Apps\Custom, where your own installers from the installation media end up on the new PC.

The IDs are the ones Winhance writes into config files, for example external-app-brave. Open a saved .winhance file in a text editor and look under ExternalApps to find them.

& "$env:ProgramFiles\Winhance\Winhance.exe" --install-apps external-app-brave,external-app-onlyoffice

Winhance opens on the External Apps tab, ticks those apps, and installs them one after another. When it's done, it lists anything that didn't install, including IDs it doesn't know. Apps that failed stay ticked, so Install Selected Items tries them again.

Only the first window reads flags

Winhance runs one copy at a time. If it's already open, starting it again just brings the open window to the front, and the flags are ignored. If Winhance can't read the flags, it writes the error to the startup log and opens without installing anything.
