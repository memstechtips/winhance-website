Contributing

How to report bugs, suggest features, ask questions, fix translations and support Winhance.

Winhance is built by one person, Marco, who is also using it to learn software development. The most useful help is a clear issue on GitHub.

Report a bug or suggest a feature

Open GitHub Issues and pick the template that fits:

TemplateUse it for
Report a bug or an issueSomething doesn't work or behaves unexpectedly.
Suggest an improvement for an existing featureA change to something Winhance already does.
Propose a new featureNew functionality, a UI or performance improvement, or software you'd like added to External Apps.

Search the open and closed issues first, so the same report isn't filed twice. For bugs, include your Winhance version, your Windows version, edition and architecture, the steps that cause the problem, and your log file. Troubleshooting shows where to find each.

Ask a question

Questions that aren't bugs or feature requests go in the GitHub discussion, where other users can help too. To report something that shouldn't be public, such as a security problem, email contact@memstechtips.com instead of opening an issue.

Translations

Winhance is available in 29 languages. You choose yours under Settings > Language. Each language is one file in the repository, in src/Winhance.Core/Features/Common/Localization, named by language code: en.json, de.json, pt-BR.json and so on. If a translation is wrong or reads badly, open an issue that names the language, the text as it appears in the app, and what it should say.

Pull requests

Marco prefers to write Winhance's code himself, because building it is how he learns. A pull request may not be merged, so please don't take that personally. The best way to share a fix or an idea is to describe it in an issue, with a code snippet if you have one.

Support the developer

Winhance is free. If it has been useful to you, you can support its development at the Winhance store. The Support button in Winhance's title bar shows the current sponsors and supporters and links to the same store.
