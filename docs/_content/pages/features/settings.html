Settings

Winhance's own preferences: the display language, the app theme, importing and exporting configs, and creating a System Restore point.

Open Settings from the bottom of the sidebar. The page includes Winhance's appearance, configs and profiles, background and update preferences, background tasks and system protection.

Language

Choose the language for Winhance's interface from the Language list. The change applies straight away, with no restart, and Winhance remembers it next time. Winhance starts in English until you pick another language.

Winhance Theme

The Winhance Theme list sets how Winhance looks:

  • System matches whether Windows is in light or dark mode.
  • Light and Dark keep Winhance in that mode whatever Windows uses.

This only changes Winhance. To switch Windows itself between light and dark, use Customize > Windows Theme.

Config file

Under Configs & profiles, the Config file card has two buttons. While Settings is open, Ctrl+I and Ctrl+E press them for you.

Export

Export saves a .winhance config file with the current Optimize and Customize settings on this PC, plus the apps you have checked on both tabs of Software & Apps.

Import

Import opens the Import Config dialog, where you pick a source:

OptionWhat it loads
Import my own configA .winhance file you choose.
Import recommended configWinhance's recommended settings.
Import backup configThe backup Winhance saved of your settings the first time it ran.
Restore Windows defaultsWindows' own default for every setting.

Click Continue and Winhance opens the config in Config Review mode, so you can check every change before you apply it. To apply it straight away instead, tick Skip review and apply immediately. That turns on a few more choices: Install, Uninstall or Select Only for the Windows apps and external apps in the file, and whether to run Clean Taskbar and Clean Start Menu.

The Configuration files guide covers the file format and sharing configs between PCs.

Settings profiles

Use profiles to switch Optimize and Customize settings together. Unlike importing a config, switching profiles never installs or removes apps, and Winhance changes only settings that differ.

Winhance includes Winhance Focus for gaming or recording and Winhance Everyday to restore Windows defaults for the settings Focus changes, without touching other settings. Before Winhance restores the Optimize and Customize settings saved before Winhance first made changes. To keep your own everyday choices, save them as a custom profile.

To create your own, use Save the current settings as a profile, give it a name and click Save. You can also choose Add from file to load a Winhance config as a settings-only profile. Use Edit in Builder to change a profile without applying it. Deleting a profile removes its file, not the settings currently applied to Windows.

Some changes require a restart. Settings that a profile does not include stay as they are; Winhance can remind you about them so you can add them in Builder. Turn on Re-apply the active profile when I sign in if you want Winhance to restore the profile's settings at sign-in. Turn it off if Windows settings keep changing back after a restart. The sign-in option requires a regular installation.

Background and updates

Under Run Winhance in the system tray, choose whether closing or minimizing the window hides it in the system tray instead. Click the tray icon to bring Winhance back, or use its menu to switch profiles, check for app updates or exit the app. Start in the system tray when I sign in requires a regular installation in a protected folder and is not available when running with another user's administrator rights.

Check for software updates sets the frequency to Never, Every day or Every week. Under When software updates are found, choose whether to receive a notification or install them automatically. Winhance also checks for its own updates on startup and daily; the separate Winhance update preference lets you receive a notification or install them automatically.

Background tasks

Keep removed apps removed controls how Winhance handles Windows apps that return after an update. Winhance can do this itself or use Task Scheduler and scripts. You can check now, see the last check and stop keeping individual apps removed. See Windows apps for details.

System Restore Point

Click Create Restore Point to make a Windows System Restore point before you change anything. If System Restore is turned off for drive C:, Winhance turns it on first. You can roll back to the restore point from Windows' own System Restore if a change causes trouble.

Winhance also offers to create a restore point the first time it starts.

Updates

To check for a new Winhance release immediately, open More at the bottom of the sidebar and choose Check for Updates. The automatic update preferences are under Background and updates.
