Settings

Winhance's own preferences: the display language, the app theme, importing and exporting configs, and creating a System Restore point.

Open Settings from the bottom of the sidebar. The page is titled Winhance Settings and has three groups: General, Configuration and System Protection. These options change Winhance itself, not Windows.

Language

Choose the language for Winhance's interface from the Language list. The change applies straight away, with no restart, and Winhance remembers it next time. Winhance starts in English until you pick another language.

Winhance Theme

The Winhance Theme list sets how Winhance looks:

  • System matches whether Windows is in light or dark mode.
  • Light and Dark keep Winhance in that mode whatever Windows uses.

This only changes Winhance. To switch Windows itself between light and dark, use Customize > Windows Theme.

Backup & Restore

The Backup & Restore card has two buttons. While Settings is open, Ctrl+I and Ctrl+E press them for you.

Export

Export saves a .winhance config file with the current Optimize and Customize settings on this PC, plus the apps you have checked on both tabs of Software & Apps.

Import

Import opens the Import Config dialog, where you pick a source:

OptionWhat it loads
Import my own configA .winhance file you choose.
Import recommended configWinhance's recommended settings.
Import backup configThe backup Winhance saved of your settings the first time it ran.
Restore Windows defaultsWindows' own default for every setting.

Click Continue and Winhance opens the config in Config Review mode, so you can check every change before you apply it. To apply it straight away instead, tick Skip review and apply immediately. That turns on a few more choices: Install, Uninstall or Select Only for the Windows apps and external apps in the file, and whether to run Clean Taskbar and Clean Start Menu.

The Configuration files guide covers the file format and sharing configs between PCs.

System Restore Point

Click Create Restore Point to make a Windows System Restore point before you change anything. If System Restore is turned off for drive C:, Winhance turns it on first. You can roll back to the restore point from Windows' own System Restore if a change causes trouble.

Winhance also offers to create a restore point the first time it starts.

Updates

Update checks are not on this page. Open More at the bottom of the sidebar and choose Check for Updates.
