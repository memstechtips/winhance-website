Unattend and WIMUtil

Two tools for setting up new PCs: Unattend builds an autounattend.xml answer file, and WIMUtil puts it on Windows installation media.

Where to find them

Both sit at the bottom of the sidebar, above Settings:

  • Unattend is locked until you switch to Builder mode with Autounattend as the target. Hover over it to see why it is locked.
  • WIMUtil works in Normal and Builder mode, and is locked while you are in Config Review mode.

You can use them together or on their own. Unattend writes a file you can copy to any installation USB drive. WIMUtil can also take an answer file you made somewhere else, or none at all.

Unattend

An answer file, autounattend.xml, tells Windows Setup what to do so you do not have to click through it. The Unattend page holds the settings that only make sense in an answer file, such as the Windows edition, the user accounts, which setup screens Windows shows, and what runs after setup. Everything else in the file comes from the rest of Winhance: the Windows apps you check are removed, the external apps you check are installed for everyone on the new PC, and the Optimize and Customize settings you include are applied.

  1. Switch to Builder mode

    Pick Builder in the mode switcher in the title bar, choose where to start from, then choose Autounattend as the target in the Builder bar. Builder mode never changes this PC.

  2. Make your choices

    Fill in the Unattend page, then check apps and include settings on the other pages.

  3. Save the file

    Click Save autounattend.xml in the Builder bar.

WIMUtil

WIMUtil, short for Windows Installation Media Utility, turns a Windows 10 or Windows 11 ISO into your own installation media. It works in four steps:

StepWhat you do
Select Windows ISOPick an ISO and a working folder, and Winhance extracts the ISO there. You can also convert the Windows image between WIM and ESD format.
Add XML FileOptional. Generate an answer file with Winhance, download the UnattendedWinstall answer file, or select one you already have. Winhance checks the file and lists anything that could make Windows Setup fail, but you can always continue.
Extract and Add DriversOptional. Copy the drivers from this PC, or from a folder, onto the media so Windows Setup installs them before the first startup screens.
Create New ISOSave a new ISO file, or write the media straight to a USB drive. Writing to a USB drive erases it first.

Step 1 has to finish before the others unlock.

Reinstalling Windows on the same PC

Extracting this PC's drivers in step 3 means your network, storage and graphics drivers are in place as soon as Windows starts, with no hunting for downloads.
