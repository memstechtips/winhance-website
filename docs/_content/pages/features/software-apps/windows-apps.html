Windows Apps & Features

Remove the apps, capabilities and optional features that ship with Windows, stop them coming back, and restore them if you change your mind.

What you can remove

The Windows Apps & Features tab of Software & Apps lists three kinds of items:

  • Windows Apps: the Store-style apps Windows installs for you, such as Clipchamp, Copilot, Microsoft Edge and OneDrive.
  • Windows Capabilities: smaller add-ons such as Internet Explorer, PowerShell ISE, Steps Recorder and WordPad.
  • Windows Optional Features: features such as Hyper-V, .NET Framework 3.5, Windows Sandbox and Recall.

Each item shows whether it is installed. Two other labels are worth checking before you remove anything:

  • Permanent means the item cannot be reinstalled once it is gone. Cortana, Skype, Paint 3D and the Copilot+ PC AI packages are examples.
  • Warning means removing the item may cause system instability. Microsoft Edge and App Installer carry this label.

Remove items

  1. Check what you want gone

    Check the items you want to remove. You can check items marked Not Installed too. Winhance adds them to its removal list, so they get removed if Windows installs them later.

  2. Click Uninstall Selected Items

    The Confirm Removal dialog lists everything you checked.

  3. Keep continuous removal on

    Leave Save removal scripts to ensure continuous removal checked (it is on by default), then click Continue. Winhance removes the items and sets up the scheduled tasks described below.

Clearing the checkbox clears all saved removals

If you clear Save removal scripts to ensure continuous removal, Winhance removes the items once and then deletes every removal script and task it saved before, not just the ones for this run.

How removal works

Winhance writes the removal as PowerShell scripts in C:\ProgramData\Winhance\Scripts, runs them straight away, and registers a scheduled task for each one so Windows cannot quietly bring the items back.

ScriptWhat it removesTask runs
BloatRemoval.ps1Every app, capability and optional feature you removed, except Edge and OneDriveAt every sign-in
EdgeRemoval.ps1Microsoft EdgeAt startup
OneDriveRemoval.ps1OneDriveAt every sign-in

The tasks live in a Winhance folder in Task Scheduler and run as SYSTEM. Each time you remove more items, Winhance adds them to the list in BloatRemoval.ps1 instead of replacing it.

For apps, BloatRemoval.ps1 first removes the provisioned copy, so new user accounts do not get the app, then removes it for every existing user. It removes capabilities, and turns optional features off without forcing a restart. It keeps a log in C:\ProgramData\Winhance\Logs\BloatRemovalLog.txt.

To see the scripts, open More in the sidebar and choose Winhance Scripts. More > Change History lists what Winhance removed and installed.

Microsoft Edge and OneDrive

Edge and OneDrive each get their own script because they need more than a package removal.

  • EdgeRemoval.ps1 removes Edge (legacy and Chromium) and Edge Update. It leaves the Edge WebView2 runtime alone, because other apps need it. It also sets up a redirect, based on AveYo's OpenWebSearch, so links Windows sends to Edge, such as web results in Start and Search, open in your default browser. A second task, OpenWebSearchRepair, puts the redirect back at sign-in if something overwrites it.
  • OneDriveRemoval.ps1 uninstalls OneDrive, removes its scheduled tasks and Start menu shortcuts, and stops it installing itself for new users. Your files in %USERPROFILE%\OneDrive are kept.

Stop continuous removal

Click Help on the Software & Apps page. Under Winhance Status: you see three icons, one each for Bloat Removal, Microsoft Edge and OneDrive.

  • A colored icon means the script or its task exists, so continuous removal is active.
  • A grey icon means neither exists.

Click a colored icon to delete that script and unregister its task. This only stops future removals. It does not reinstall anything.

Restore an item

Check the item and click Install Selected Items. Items marked Permanent cannot be restored.

  • Winhance first takes the item off the list in BloatRemoval.ps1, so the sign-in task leaves it alone. For Edge or OneDrive it deletes that app's script and task, and for Edge it also removes the browser redirect.
  • Apps install through WinGet. If WinGet cannot get a package, which usually means a regional restriction, Winhance asks before downloading it from Microsoft's servers through store.rg-adguard.net.
  • If Windows Update is disabled, Store installs cannot finish. Winhance offers to change the update policy to Paused for a long time and try again.
  • Capabilities and optional features are turned back on in a separate PowerShell window. Winhance cannot see the result, so watch that window, then click Refresh.

Reinstall through Winhance

If you reinstall an app from the Microsoft Store or anywhere else while it is still on the removal list, the BloatRemoval task removes it again at your next sign-in. Restore it from this tab, or stop continuous removal first.

Other settings are applied once

Only app removal runs again in the background. Settings on the Optimize and Customize pages are applied once when you change them, and Winhance does not re-apply them if Windows or you change them later.
