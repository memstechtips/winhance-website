Windows Apps & Features

Remove the apps, capabilities and optional features that ship with Windows, stop them coming back, and restore them if you change your mind.

What you can remove

The Windows Apps & Features tab of Software & Apps lists three kinds of items:

  • Windows Apps: the Store-style apps Windows installs for you, such as Clipchamp, Copilot, Microsoft Edge and OneDrive.
  • Windows Capabilities: smaller add-ons such as Internet Explorer, PowerShell ISE, Steps Recorder and WordPad.
  • Windows Optional Features: features such as Hyper-V, .NET Framework 3.5, Windows Sandbox and Recall.

Each item shows whether it is installed. Two other labels are worth checking before you remove anything:

  • Permanent means the item cannot be reinstalled once it is gone. Cortana, Skype, Paint 3D and the Copilot+ PC AI packages are examples.
  • Warning means removing the item may cause system instability. Microsoft Edge and App Installer carry this label.

Remove items

  1. Check what you want gone

    Check the items you want to remove. You can check items marked Not Installed too. Winhance adds them to its removal list, so they get removed if Windows installs them later.

  2. Click Uninstall Selected Items

    The Confirm Removal dialog lists everything you checked.

  3. Keep the apps removed

    Leave Keep these apps removed after Windows updates checked (it is on by default), then click Continue. Winhance removes the items and adds them to the list of apps it keeps removed.

Installed or portable

Keeping apps removed works on an installed copy and on a portable copy. By default Winhance does the checking itself, with no scripts and no SYSTEM task. If you prefer Windows Task Scheduler and script files, choose that under Settings > Background tasks.

How removal works

Winhance removes the items straight away and adds them to a list. Winhance checks that list every time you open it, and removes anything Windows has brought back. The check runs quietly in the background and never holds up the window. If you turned on Start in the system tray when I sign in or Re-apply the active profile when I sign in, it also checks at sign-in through the one sign-in task those options use. Each time you remove more items, Winhance adds them to the list instead of replacing it.

The setting How Winhance keeps your system this way has two choices. Winhance does it is the recommended one: no scripts are saved and no SYSTEM task exists. Task Scheduler and scripts saves a script for each removal in C:\ProgramData\Winhance\Scripts and runs it from a scheduled task as SYSTEM. That folder cannot be moved, because Windows runs those scripts with full rights, so they must sit in a folder only administrators can change. Switching modes asks you first and moves your list across.

For apps, Winhance first removes the provisioned copy, so new user accounts do not get the app, then removes it for every existing user. It removes capabilities, and turns optional features off without forcing a restart. The check writes a log in C:\ProgramData\Winhance\Logs. The C:\ProgramData\Winhance folder is locked to administrators, so a normal user cannot change what the task runs.

Open Settings > Background tasks to see when the last check ran and what it found. Check now runs it straight away and Open log opens the log folder. In Task Scheduler mode each script has its own card that shows whether it will really run: a script without its task, a task without its script, or a disabled task removes nothing, and the card says so. Items being removed lists what each one removes. More > Change History lists what Winhance removed and installed.

Microsoft Edge and OneDrive

Edge and OneDrive go on the same list as any other app, and removing them does more than a package removal.

  • Removing Edge removes Edge (legacy and Chromium) and Edge Update. It leaves the Edge WebView2 runtime alone, because other apps need it, unless you remove WebView2 too. It also sets up a redirect, based on AveYo's OpenWebSearch, so links Windows sends to Edge, such as web results in Start and Search, open in your default browser. A second task, OpenWebSearchRepair, puts the redirect back at sign-in if something overwrites it.
  • Removing OneDrive uninstalls it, removes its scheduled tasks and Start menu shortcuts, and stops it installing itself for new users. Your files in %USERPROFILE%\OneDrive are kept.

Stop keeping apps removed

Open Settings > Background tasks. Under Keep removed apps removed, each app on the list has a Stop keeping removed button. Turn the switch off to stop all checks. In Task Scheduler mode, turning it off asks first, then removes the tasks and their scripts.

This only stops future removals. It does not reinstall anything.

Restore an item

Check the item and click Install Selected Items. Items marked Permanent cannot be restored.

  • Winhance first takes the item off the keep-removed list, so the background task leaves it alone. For Edge it also removes the browser redirect.
  • Apps install through WinGet. If WinGet cannot get a package, which usually means a regional restriction, Winhance asks before downloading it from Microsoft's servers through store.rg-adguard.net.
  • If Windows Update is disabled, Store installs cannot finish. Winhance offers to change the update policy to Paused for a long time and try again.
  • Capabilities and optional features are turned back on in a separate PowerShell window. Winhance cannot see the result, so watch that window, then click Refresh.

Reinstall through Winhance

If you reinstall an app from the Microsoft Store or anywhere else while it is still on the removal list, Winhance removes it again the next time it checks, which is when you open it or, if you use a sign-in option, at sign-in. Restore it from this tab, or stop keeping it removed first in Settings > Background tasks.

Other settings are applied once

Settings on the Optimize and Customize pages normally apply once when you change them. If you have enabled Re-apply the active profile when I sign in, Winhance also restores settings covered by your active profile at sign-in.
