External Software

Install popular third-party apps in one batch, with WinGet, the Microsoft Store, Chocolatey or a direct download as the source.

What's in the list

The External Software tab of Software & Apps lists over 200 apps, grouped into these categories:

  • Browsers
  • Compression
  • Customization Utilities
  • Development Apps
  • Document Viewers
  • File & Disk Management
  • Gaming
  • Imaging
  • Messaging, Email & Calendar
  • Multimedia (Audio & Video)
  • Online Storage & Backup
  • Optical Disc Tools
  • Other Utilities
  • Privacy & Security
  • Remote Access
  • Runtimes & Dependencies

Each app has a small link button next to its name that opens the developer's website, so you can read about it before you install.

Install apps

  1. Check the apps you want

    Use the search box or browse the categories, and check as many apps as you like.

  2. Click Install Selected Items

    Confirm the list in the Confirm Installation dialog. Winhance installs the apps one after another and shows the progress of each.

  3. Check the result

    Winhance refreshes the install status when it finishes. Apps that failed stay checked, so clicking Install Selected Items again retries only those.

To remove apps, check them and click Uninstall Selected Items.

Where apps come from

Winhance tries each source the app supports, in this order, and stops at the first one that works:

  1. WinGet, from the WinGet community repository.
  2. WinGet with the Microsoft Store source, for apps that are also published in the Store.
  3. Chocolatey, for apps that have a Chocolatey package. If Chocolatey is not installed, Winhance installs it first.
  4. Direct download of the app's installer, for apps that have a download link.

A few apps are not on WinGet at all, and those go straight to the direct download. When an app installs as a portable program, Winhance adds Start menu shortcuts for it.

WinGet comes with Winhance

Winhance ships its own copy of WinGet and uses it first, so you do not need WinGet installed in Windows. It only uses the copy in Windows if its own is missing.

How Winhance knows what is installed

The Installed status comes from several places: WinGet, Chocolatey, Store packages, the list of installed programs in Windows, and known install folders. When you uninstall, Winhance uses the tool that matches how the app was found, so an app installed with Chocolatey is removed with Chocolatey, and so on.

Updating and managing apps

Winhance installs and uninstalls apps, but it does not update them. For updates and ongoing management, install UniGetUI from the Other Utilities category. It is a window for WinGet, Chocolatey and other package managers.

Request an app

If an app you use is missing, open a feature request on GitHub with the app's name and its WinGet ID if it has one.
