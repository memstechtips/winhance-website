Software & Apps

Remove the apps and features that come with Windows, and install third-party apps, from one page with two tabs.

The two tabs

Open Software & Apps from the top of the sidebar. The page has two tabs:

Windows Apps & FeaturesRemove built-in apps, Windows capabilities and optional features, and keep them removed. External SoftwareInstall and uninstall third-party apps, grouped by category.

Both tabs work the same way: check the items you want, then click a button in the bar above the list.

Find and select items

  • Type in the search box at the top right (Type here to search...) to filter the current tab. It matches names and descriptions.
  • Use Select All, Select All Installed or Select All Not Installed above the list to check items in bulk. In Table View, the checkbox in the first column header selects everything.

Buttons

ButtonWhat it does
Install Selected ItemsInstalls the checked items. On the Windows tab this restores apps and features you removed.
Uninstall Selected ItemsRemoves the checked items.
RefreshChecks again what is installed. The shortcut is F5.
HelpShows a short guide for the current tab. On the Windows tab it also shows the removal status icons.

In Normal mode, both action buttons stay disabled until you check at least one item. Winhance asks you to confirm and lists the items before it starts. When the window is narrow, the button labels shrink to icons; hover over one to see its name.

Views and sorting

The three buttons next to Help switch between Card View, Table View and Compact View. Winhance remembers the view you pick.

  • Card View shows each item with its icon, description and status labels.
  • Table View shows columns you can sort by clicking a header. The Windows tab has Name, Description, Type, Status and Installable. The External Software tab has Name, Description, Group and Status.
  • Compact View fits many items on screen, with small status icons beside each name.

In card and compact view, the Sort menu offers Name A-Z (Installed First) (the default), Name A-Z and Name Z-A. It is disabled in table view, where the column headers do the sorting.

Status labels

LabelMeaning
Installed / Not InstalledWhether the item is on this PC right now.
InstallableWindows tab only. You can reinstall the item after removing it.
PermanentWindows tab only. Once removed, the item cannot be reinstalled.
WarningWindows tab only. Removing the item may cause system instability.

Card view only shows the Installed, Permanent and Warning labels. Table and compact view show the install status of every item and, on the Windows tab, whether it can be reinstalled. In every view you can hover over any label for a short explanation.

In Builder and Config Review mode

The mode switcher in the title bar changes what the checkboxes mean:

  • Builder mode never touches this PC. Your checks are saved into the config or autounattend.xml you are building, and a banner above the list says what will happen to them. In an answer file, checked Windows apps are removed during installation and checked external apps are installed for everyone on the new PC.
  • Config Review mode shows the apps from a config you imported. Use the Install Selected Items and Uninstall Selected Items toggles to choose what happens to the checked apps when you apply the config, or uncheck everything to skip apps.

See Configuration files for how configs are saved and imported.
