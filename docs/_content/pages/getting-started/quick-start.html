Quick start

Open Winhance for the first time, learn the layout and the three modes, apply recommended settings and save your choices to a config file.

First launch

Accept the User Account Control prompt. While the app loads, Winhance saves a backup config: a file with the current value of every setting it manages, so you can put them back later. It does this once, on the first launch.

When loading finishes, a System Protection dialog offers to create a System Restore point as well. Click Create Restore Point. It captures Windows before Winhance changes anything, and Winhance turns System Restore on for drive C: if it was off. If you click Skip, you can create one later from Settings.

On Optimize and Customize, each setting is a card with a toggle or a drop-down. The search box finds a setting by name. The View menu turns on Technical Details, which shows the registry values and scripts behind each setting.

The three modes

The Winhance Mode switch sits in the title bar.

  • Normal is where Winhance starts. A change applies to this PC as soon as you make it.
  • Builder records your choices for a file instead of applying them. Start from this PC's current settings, the recommended settings, Windows defaults, or a saved file, then click Save Config or Save autounattend.xml. Nothing on this PC changes.
  • Config Review loads a config file and compares it with this PC. You approve or skip each change, then click Apply Config. Nothing applies before that.

When you leave Builder or Config Review with unsaved work, Winhance asks before it throws that work away.

Make your first change

The quickest start is Winhance's recommended value for every setting on a page.

  1. Open a page

    Click Optimize or Customize in the sidebar. To limit the change to one area, open a section such as Privacy & Security.

  2. Apply recommended settings

    Open Quick Actions and choose Apply Recommended Settings. Winhance tells you how many settings it will change. Click OK to go ahead.

  3. Restart Explorer if asked

    Some taskbar and File Explorer settings only show up after Explorer restarts. When Winhance says so, click Restart Explorer. A few settings need a full restart of Windows.

To change one setting instead, flip its toggle or pick a value from its drop-down. Cards marked Recommended or Default show which value is Winhance's suggestion and which is the Windows default. To go back, use Quick Actions > Reset to Windows Defaults.

Read before you apply

The recommended settings suit most PCs, but not every PC. Turn on Technical Details to see exactly what each setting writes before you apply a whole page.

Save your choices

A config file (.winhance) holds your settings and app choices so you can reapply them later or on another PC.

  • To save this PC as it is now, go to Settings > Backup & Restore and click Export.
  • To build a file without changing this PC, switch to Builder, make your choices, and click Save Config.

To use a file, click Import under Backup & Restore. You can import your own file, the recommended config, your backup config, or Windows defaults. Winhance opens it in Config Review unless you tick Skip review and apply immediately. The Configuration files guide covers this in detail.
